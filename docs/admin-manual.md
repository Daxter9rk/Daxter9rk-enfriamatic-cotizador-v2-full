# Manual de administrador

1. Inicie sesión y confirme que el dashboard no muestra excepciones.
2. Cree cliente, instalación y equipo. Inactive en lugar de borrar.
3. Cree una solicitud, seleccione prioridad y asigne operador activo.
4. Supervise transiciones y borradores desde Solicitudes y Cotizaciones.
5. Antes de emitir revise partidas, descuento, IVA y vista previa.
6. Una emisión exitosa bloquea la cotización y habilita descarga privada.
7. Para corregir, use **Crear corrección**; nunca edite el original.
8. Revise notificaciones y auditoría en Actividad.
9. Gestione datos comerciales y watermark DEV en Configuración.
10. Si PDF falla, el quote sigue draft, conserva folio y permite reintento.

No cambie su propio rol/estado, no comparta contraseñas y no invente datos
fiscales. App Check y despliegues requieren el procedimiento operativo.
